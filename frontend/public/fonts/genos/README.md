# Genos

Unmodified variable TrueType fonts from Google Fonts, downloaded 2026-11-16.
Designer: Robert Leuschke. Normal and italic faces support weights 100–900.

Source: https://github.com/google/fonts/tree/main/ofl/genos
License: SIL Open Font License 1.1; see OFL.txt alongside the font files.

Served locally to avoid a third-party font request. The normal face is preloaded;
the italic face is requested only when needed. Interface weights are controlled
in `src/typography.css`; code and copyable terminal commands remain monospaced.
