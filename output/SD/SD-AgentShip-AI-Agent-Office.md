# AgentShip AI Agent Office

2026-11-10 · 方案记录 · 待实现

把 AgentShip 的登录后工作台做成可交互的 3D 办公室。用户从大厅选择一条需求运行，在项目办公室查看 Agent 的分工、执行进度和阻塞原因，点开工位即可查阅产物或进入运行操作页。交互参考为可缩放的斜俯视场景、可点击的对象和右侧详情面板。[3D 工作台参考视频](https://www.instagram.com/reel/DeG2mQszTrc/)

## 办公室与现有数据的对应关系

| 界面元素 | 数据与操作 |
|---|---|
| 大厅的项目卡片 | 当前用户可见的需求运行，来自现有运行列表。选择卡片后加载该次运行的办公室。 |
| 房间与工位 | 从本次运行固定的阶段、节点和依赖生成布局，支持同一阶段的多个工位并行。 |
| Agent 角色 | 使用节点已选角色及其任务状态。两个角色同时执行时，两个工位同时显示工作状态。尚未派发的角色显示待派发。 |
| 待回复提示 | 任务进入待回复时显示提示。点开查看状态，并在有权限时进入该次运行的操作页处理。 |
| 检查区与维修区 | 显示实际检查结论、修复轮次与复查进度。进入维修区的依据是后端记录的修复状态。 |
| 交付柜 | 展示节点产物及其版本、提交或路径等现有信息。 |

## Claw3D Demo

状态为待实现。以已预览的三层园区为场景，优先复用 Claw3D 的角色渲染、寻路和工位动画。首个演示用本地示例数据驱动，展示 Agent 从等候点沿过道走到分配的工位、坐下并进入工作状态。接入实际运行时，AgentShip 的运行数据决定角色状态，现有后端继续负责调度、权限、Codex 执行和人工操作。[Claw3D 办公室架构](https://github.com/iamlukethedev/Claw3D/blob/main/CODE_DOCUMENTATION.md#office-architecture)

园区按约 160,000 sq ft 用地规划。办公楼分配约 80,000 sq ft，花园与菜园约 40,000 sq ft，停车区约 40,000 sq ft。

| 楼层 | 空间与工位 |
|---|---|
| 一楼 | 大厅、Reception 前台、健身房、咖啡厅和员工食堂。 |
| 二楼 | 财务、销售、HR 等部门的办公区、会议室、茶水间和会客区。每个工位配 27 英寸 4K 显示器。 |
| 三楼 | 产品与技术办公区、茶水间、游戏区和会议室。每个工位配 34 英寸 4K 显示器。 |

Demo 验收以浏览器中的可见行为为准。

- 至少一名 Agent 在园区内沿可通行路径到达指定工位，按顺序完成行走、坐下和工作动画。
- 支持拖动 360° 旋转、缩放、平面图和东南西北预设视角。切换楼层后可选择房间近看，并可使用室内视角。
- 切换镜头与楼层只改变观看位置。工位归属和 Agent 工作状态由同一份示例运行数据驱动。

建议首个动画先在一个楼层内验证，三层园区均可查看。跨楼层寻路可在单层流程跑通后再评估。

## 实现顺序

先完成上方 Claw3D Demo，确认角色表现和园区交互后，再进入以下业务集成步骤。

1. **单次运行办公室。** 在运行详情加入「办公室 / 时间线」切换。沿用 React 和 TypeScript，用 Three.js 与 React Three Fiber 渲染斜俯视场景，提供缩放、工位选择和右侧详情。键盘用户可通过工位列表选择相同节点。移动端或 3D 加载失败时可使用时间线。
2. **连接运行快照。** 办公室和时间线共享 `GET /api/runs/{runId}` 及现有每 5 秒刷新的机制。按节点、角色和任务标识更新画面。当前 `/events` 提供运行版本变化提示，逐动作回放需要更细的事件记录。
3. **上线大厅入口。** 单次运行办公室通过验收后，将大厅设为登录后默认入口。大厅复用 `GET /api/runs` 的授权和分页，选定运行后加载对应场景。需求、流程、Agent 配置和本机设备继续通过工作台入口访问。

办公室使用现有数据展示状态。调度、权限、Git、Codex 执行、检查与修复均沿用 AgentShip 的现有逻辑。回复、重试等操作由现有运行操作页处理，访问与动作资格由后端校验。

## 第一版验收

- 用本地演示发起运行，看到两个 Agent 的并行任务分别显示在各自工位。
- 让检查进入「需修复」，核对办公室依次显示修复和原检查节点的新波次，并与时间线对账。
- 触发 Agent 待回复，点击工位找到阻塞点，进入同一运行的操作页回复，确认办公室随后显示实际进度。
- 点击已完成工位查看节点产物，并验证切换时间线时仍在同一次运行。
