# AgentShip PostgreSQL 数据字典 v0.5

[字段清单 CSV](data-dictionary.csv)按 DDL 逐列列出类型、格式、可空性、默认或生成方式、分类、来源责任、行内约束和待确认的留存。复合键、触发器、部分索引及权威约束见 [DDL](agentship-postgresql-ddl.sql)，关系见[数据设计](../SD-AgentShip-data.md)。

清单来自 49 张设计表的 413 个字段，含独立 ALTER 定义。数据分类和保存策略为拟议，保存期限与清理授权待决定。

| 数据域 | 权威与访问范围 | 主要审核 |
|---|---|---|
| 身份配置 | 平台身份与配置。账号凭据、联系资料和权限受保护。 | 创建／授权变更审计。资料留存待 SA-D07/09。 |
| 定义版本 | 平台流程配置。需求规则和 Agent 指令限制访问。 | 封存版本及来源。版本和配置留存待 SA-D05/09。 |
| 运行编排 | 平台运行；设备提供状态。设备证明、尝试和工作内容受保护。 | 任务变更和回报收据。租约、执行历史留存待 SA-D08/09。 |
| 运行协作 | 平台聊天与权限。对话、受理序号、来源事件、关联收件箱和授权受保护。 | 占用、答复、取消与修订。问答和对话留存待 SA-D03/06/09。 |
| 证据运维 | 平台证据；外部结果由供应商证实。代码、产物、审计受保护。 | 原请求、核对与关键审计。工件和审计留存待 SA-D02/09。 |

物理列名供实现和校验。前端只读取当前授权的业务投影。凭据与联系资料不得随运行、日志或供应商消息输出。
